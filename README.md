# Pooja Parlapalli - Personal Portfolio

Welcome to my personal portfolio repository! This responsive, interactive website showcases my experience, projects, and skills as a Full-Stack Software Engineer. It also features a custom-built, integrated AI chatbot that visitors can interact with to learn more about my background.

🌍 **Live Demo:** [https://pooja401.github.io/](https://pooja401.github.io/)

## ✨ Features

* **Interactive AI Chatbot:** A custom JavaScript-based chat widget embedded in the site that acts as a personal assistant to answer questions about my work history, skills, and education.
* **Modern UI/UX:** Clean, professional design with smooth scroll animations (`IntersectionObserver`), hover effects, and a dynamic tag cloud for skills.
* **Dark/Light Mode:** A fully functioning theme toggle (lightbulb icon) that transitions colors smoothly for better readability.
* **Experience Timeline:** A visually engaging, vertical timeline detailing my professional journey at SEMICAB and Goldman Sachs.
* **Responsive Design:** Fully mobile-friendly layout that adapts beautifully to tablets and smartphones.
* **Direct Downloads:** Easy access to download my latest resume directly from the header and navigation bar.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and content layout.
* **CSS3:** Custom styling, flexbox/grid layouts, CSS variables, and keyframe animations.
* **JavaScript (Vanilla):** Logic for the AI chatbot, scroll animations, and theme toggling.
* **FontAwesome:** Icons for navigation, social links, and the chat interface.
